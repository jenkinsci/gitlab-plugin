When checked, this status update looks up the commit's merge request pipeline and explicitly targets it via pipeline_id, instead of letting GitLab decide based on the commit SHA, ref and status name alone.

When unchecked, this is explicitly disabled here, even if the global option Manage Jenkins > System > GitLab > Attach commit status updates to the merge request pipeline is enabled.

To inherit the global option instead, omit the attachStatusToMergeRequestPipeline argument in Pipeline script. Saving this form (or generating a snippet with the Snippet Generator) always stores an explicit true or false.
