Comma-separated lists of branch patterns used to filter builds. For push events, the pushed branch is checked. For merge request events, the target branch is checked. Branches matching an Exclude pattern are not allowed to trigger a build. If Include patterns are specified, the checked branch must match at least one of them. If Include is empty, all branches that do not match an Exclude pattern are allowed. If both fields are empty, no branch filtering is performed.

Patterns use Ant-style path matching. For example: 

# Allow only main and release branches:
Include: main,release/*

# Exclude the old release branch:
Exclude: release/old
