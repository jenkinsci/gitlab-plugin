Filter merge requests by their labels using the Include and Exclude fields.

  • Include: Comma-separated labels. If specified, a merge request must have at least one matching label to be allowed. Multiple included labels use OR logic.
  • Exclude: Comma-separated labels. A merge request is rejected if it contains any matching excluded label.

If Include is empty, no label is required. If Exclude is empty, no labels are excluded. If both fields are empty, no label filtering is applied.

Label matching is exact and case-sensitive. Surrounding whitespace is trimmed from each configured label.

Example:

Include: bug,feature
Exclude: WIP,blocked

This allows merge requests containing either bug or feature, provided they do not contain WIP or blocked.
